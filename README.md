## Featured Projects

**RAG Research Agent** — `LangChain · LangGraph · FastAPI · React`
Hybrid retrieval (BM25 + semantic + RRF) with Cohere re-ranking, RAGAS evaluation, and real-time streaming. Multi-step agentic reasoning with tool-use and reflection.

**Legal LLM Fine-Tuning** — `QLoRA · Mistral-7B · HuggingFace · PyTorch`
Fine-tuned Mistral-7B on 4,000+ legal QA pairs using QLoRA (r=16, 4-bit NF4), reducing perplexity by 31% and improving accuracy by 25%. Adapter published on HuggingFace Hub.

**Multi-Agent AI System** — `LangGraph · Redis · SQLite · OpenAI`
Planner–Executor–Critic architecture with dynamic routing and two-tier memory (Redis short-term + SQLite episodic). Extensible 7-tool registry with failure recovery.

**Sharded Real-Time Chat** — `Node.js · MySQL · Socket.IO · Redis · Docker`
Horizontally sharded MySQL via groupId partitioning with a hot → warm → cold, 3-tier archival strategy. JWT-authenticated WebSockets with Redis pub/sub for multi-instance scale.
